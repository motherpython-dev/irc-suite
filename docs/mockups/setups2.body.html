Сетапы — история заездов и резина

Режим «История» сводит заезды по этой трассе и машине: один и тот же сетап из разных дней — один столбец. Сектора есть только у текущей сессии (в истории их не записывали). Блок «Резина» — по замерам iRacing на пит-стопах: по каждому колесу три части, как отдаёт iRacing (левая, центр, правая): износ за круг и температура, плюс горячее давление колеса. В режиме организатора у столбца — чей сетап.
