# ichamps Suite

Одно приложение для организатора лиги. Модули включаются независимо и делят
общие ресурсы: один клиент iRacing, один HTTP-сервер, один значок в трее.

Полное описание задачи и этапов — [SPEC.md](SPEC.md).

## Модули

| Модуль | Состояние |
|---|---|
| **Рейс-контрол** | работает: лента инцидентов, перемотка повтора, флаги и штрафы |
| **Оверлеи трансляции** | в работе (этап 2) |
| **RUTP** | внешний агент, Suite будет им управлять (этап 4) |
| **Телеметрия** | позже (этап 5) |

## Запуск из исходников

```
pip install -r requirements.txt
python run.py
```
Панель: http://127.0.0.1:8777/

## Сборка

```
python build/make_icon.py
pyinstaller build/ichamps-suite.spec --noconfirm
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build/installer.iss
```

## Структура

```
bootstrap/            ядро: выбор версии бандла, откат, автообновление -> в exe
app/suite/
    core/
        simclient.py  ЕДИНСТВЕННЫЙ читатель irSDK: снимки, режимы, поиск пилотов
        commands.py   broadcast-команды в сим (камеры, реплей)
        modules.py    реестр модулей: включение и выключение на лету
        app.py        ядро: общие ресурсы и жизненный цикл
        server.py     HTTP + SSE, роуты ядра и динамические роуты модулей
        storage.py    слой хранения (SQLite; ichamps подключается заменой класса)
        config.py     конфиг по модулям + миграция со старого клиента
        tray.py       единый значок в трее
        ui/           Tk-хост и виджеты оверлеев
    modules/
        racecontrol/  инциденты, флаги, оверлей
        broadcast/    оверлеи трансляции (этап 2)
        rutp/         управление внешним агентом (этап 4)
    web/              панель Suite и панель рейс-контроля
probe.py              диагностика допущений SDK
audit.py              полнота детекта против маркеров iRacing
```

## Данные

```
%LOCALAPPDATA%\ichamps\suite    suite.sqlite3   инциденты + append-only лог событий
    config.json     настройки, раздел на каждый модуль
    suite.log       лог
    versions\       версии бандла
```

При первом запуске данные и настройки старого клиента `ichamps-racecontrol`
переносятся автоматически; прежняя папка остаётся нетронутой.
