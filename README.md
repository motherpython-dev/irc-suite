# iRC

Одно приложение для организатора лиги. Модули включаются независимо и делят
общие ресурсы: один клиент iRacing, один HTTP-сервер, один значок в трее.

Полное описание задачи и этапов — [SPEC.md](SPEC.md).

## Модули

| Модуль | Состояние |
|---|---|
| **Рейс-контрол** | работает: лента инцидентов, перемотка повтора, флаги и штрафы |
| **Оверлеи трансляции** | башня, решётка, комментаторы, дельта, пит-стопы |
| **RUTP** | внешний агент, iRC будет им управлять (этап 4) |
| **Телеметрия** | позже (этап 5) |

## Запуск из исходников

```
pip install -r requirements.txt
python run.py
```
Панель откроется окном приложения. Тот же адрес доступен и по сети —
http://127.0.0.1:8777/ — это нужно, чтобы открыть панель с планшета
или машины стюарда.

## Сборка

```
python build/make_icon.py
```

При первом запуске данные и настройки старого клиента `ichamps-racecontrol`
переносятся автоматически; прежняя папка остаётся нетронутой.

## Как это работает

Главное окно — родное окно программы на движке WebView2: интерфейс написан на
HTML (та же вёрстка работает пультом с телефона), но окном владеет iRC, а не
браузер. Открывается оно отдельным процессом: главный поток занят циклом Tk,
на котором держатся оверлеи.

При запуске открывается **только главное окно** — оверлеи, пульт и панель
рейс-контроля не появляются сами. Всё включается из него: у каждого оверлея
переключатель, состояние видно рядом.

## Демо-данные

Проверить вёрстку оверлеев без запущенного сима: переключатель «Демо-данные»
на вкладке «Обзор». Идёт синтетическая гонка — поле едет, круги закрываются,
машины заезжают на пит. Время сжато в восемь раз, заезд начинается с девятого
круга, иначе первого пит-стопа ждать полчаса.

Состав берётся из `demo-roster.json` в папке данных, иначе из встроенного
запасного списка. Выгрузить свой чемпионат:

    python tools/roster_from_ichamps.py           # список чемпионатов
    python tools/roster_from_ichamps.py 11        # выгрузить нужный

Рейс-контрол демо НЕ кормит: выдуманные инциденты осели бы в базе вперемешку
с настоящими. Настройка не сохраняется — после перезапуска читается сим.

## Графика эфира

Язык графики — трансляционный: наклонные плашки со срезанным углом, узкие
цифры, чип номера под цвет дивизиона, полоса флага сессии вдоль пилона,
счётчик кругов в шапке. Ориентир — эфирная графика NASCAR, палитра своя.

Появление и уход анимированы: окно выезжает со сдвигом и проявляется за
~220 мс, уходит тем же путём назад. Направление у каждого оверлея своё —
пилон от левого края, нижняя треть снизу, дельта и питы справа. Отключается
ключом `animate` в настройках модуля.

Примитивы живут в `modules/broadcast/style.py` и рисуются через PIL:
Tk не умеет ни наклонный текст, ни параллелограммы. Всё кэшируется по
параметрам — оверлеи обновляются несколько раз в секунду.

## Оверлеи трансляции

Выводятся **окнами поверх iRacing**: перетаскиваются мышью, запоминают место,
показом управляет пульт. В эфир попадают через захват экрана в OBS — оператор
на одном мониторе видит ровно то же, что зритель.

Пульт эфира — тоже окно поверх сима: зелёная точка показывает, что сейчас в
кадре. С телефона он же открывается по адресу `/deck` (нужно включить доступ
по сети в панели).

Для схемы с двумя машинами те же оверлеи доступны страницами и добавляются в
OBS как **browser source**:

| Оверлей | Адрес |
|---|---|
| Башня позиций | `/ov/tower` |
| Стартовая решётка | `/ov/grid` |
| Плашка комментаторов | `/ov/commentators` |
| Дельта пилотов | `/ov/delta` |
| Пит-стопы | `/ov/pits` |

Полный адрес — `http://127.0.0.1:8777` + путь.

Фон страниц прозрачный. Настройки (заголовок, число строк, режим гэпа,
машина в фокусе) — во вкладке «Оверлеи трансляции» в панели.

## Запуск из исходников без риска для боевых данных

```
set IRC_DATA_DIR=%TEMP%\irc-test
python run.py
```
Без этой переменной пробный запуск пишет настройки в рабочую папку — и потом
установленное приложение стартует с чужим портом.
