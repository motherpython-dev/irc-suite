# iRC

Одно приложение для организатора лиги. Модули включаются независимо и делят
общие ресурсы: один клиент iRacing, один HTTP-сервер, один значок в трее.

Полное описание задачи и этапов — [SPEC.md](SPEC.md).

## Модули

| Модуль | Состояние |
|---|---|
| **Рейс-контрол** | работает: лента инцидентов, перемотка повтора, флаги и штрафы |
| **Оверлеи трансляции** | башня, решётка, комментаторы, дельта, пит-стопы |
| **RUTP** | внешний агент, iRC будет им управлять (этап 4) |
| **Телеметрия** | позже (этап 5) |

## Запуск из исходников

```
pip install -r requirements.txt
python run.py
```
Панель откроется окном приложения. Тот же адрес доступен и по сети —
http://127.0.0.1:8777/ — это нужно, чтобы открыть панель с планшета
или машины стюарда.

## Сборка

```
python build/make_icon.py
pyinstaller build/irc.spec --noconfirm
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build/installer.iss
```

## Как это работает

Главное окно — родное окно программы на движке WebView2: интерфейс написан на
HTML (та же вёрстка работает пультом с телефона), но окном владеет iRC, а не
браузер. Открывается оно отдельным процессом: главный поток занят циклом Tk,
на котором держатся оверлеи.

При запуске открывается **только главное окно** — оверлеи, пульт и панель
рейс-контроля не появляются сами. Всё включается из него: у каждого оверлея
переключатель, состояние видно рядом.

### Стартовая решётка

Два ряда, как машины стоят на старте. На странице **десять мест**; если
заявлено больше, страницы листаются сами раз в 15 секунд, в подвале видно
диапазон и номер страницы. При каждом выходе в эфир показ начинается с
первой страницы.

## Пульт эфира

Одна страница на два случая: родное окно поверх iRacing (переключатель
«Пульт поверх сима» в панели или пункт в трее) и телефон в той же сети —
адрес `/deck`.

- **Вывод** — кнопки оверлеев и «Убрать всё».
- **Камера** — группы камер из `CameraInfo` сессии; активная подсвечена,
  рядом видно, кто в кадре.
- **Пилоты** — карточка на каждого: позиция, номер под цвет класса,
  разрыв до впереди идущего и до лидера, инциденты, круг по секторам.
  Нажатие на карточку переключает камеру на пилота, группа не меняется.
- **Макросы** — именованные кнопки из шагов: камера (группа и пилот в
  кадре, лидер или номер), пауза, оверлей (показать, убрать, переключить,
  только этот). Редактор — на самом пульте.

Сектора iRacing по чужим машинам не отдаёт — считаем сами по разметке
трассы (`SplitTimeInfo`) и положению машин на круге, момент пересечения
границы интерполируем между замерами. Только в LIVE. Цвета как в таймингах:
фиолетовый — лучший по полю, зелёный — личный лучший, жёлтый — медленнее.

Инциденты берутся из результатов сессии и `DriverInfo`; какой источник
живой в спектейте лиги, не проверено.

Зума в broadcast-командах нет. Что iRacing отдаёт о камере, покажет
`python tools/probe_camera.py --watch` в живой сессии.

## Демо-данные

Проверить вёрстку оверлеев без запущенного сима: переключатель «Демо-данные»
на вкладке «Обзор». Идёт синтетическая гонка — поле едет, круги закрываются,
машины заезжают на пит. Время сжато в восемь раз, заезд начинается с девятого
круга, иначе первого пит-стопа ждать полчаса.

Состав берётся из `demo-roster.json` в папке данных, иначе из встроенного
запасного списка. Выгрузить свой чемпионат:

    python tools/roster_from_ichamps.py           # список чемпионатов
    python tools/roster_from_ichamps.py 11        # выгрузить нужный

Рейс-контрол демо НЕ кормит: выдуманные инциденты осели бы в базе вперемешку
с настоящими. Настройка не сохраняется — после перезапуска читается сим.

## Графика эфира

Язык графики — трансляционный: наклонные плашки со срезанным углом, узкие
цифры, чип номера под цвет дивизиона, полоса флага сессии вдоль пилона,
счётчик кругов в шапке. Ориентир — эфирная графика NASCAR, палитра своя.

Появление и уход анимированы: окно выезжает со сдвигом и проявляется за
~220 мс, уходит тем же путём назад. Направление у каждого оверлея своё —
пилон от левого края, нижняя треть снизу, дельта и питы справа. Отключается
ключом `animate` в настройках модуля.

Примитивы живут в `modules/broadcast/style.py` и рисуются через PIL:
Tk не умеет ни наклонный текст, ни параллелограммы. Всё кэшируется по
параметрам — оверлеи обновляются несколько раз в секунду.

## Оверлеи: описания и один отрисовщик

Каждый оверлей — JSON-описание (`modules/broadcast/specs.py`): размеры,
шапка, повторяющийся элемент (строка, ячейка решётки, карточка), подвал,
палитра, шрифты. Элементы — текст, чип, плашка, картинка — стоят на своих
координатах и показывают поле данных по шаблону `{поле|формат}`.

Строит всё один HTML-отрисовщик (`web/ov/render.js`):

- **поверх iRacing** — прозрачные родные окна WebView2, все оверлеи в одном
  процессе (`iRC.exe --overlays`). Поднимается при первом выводе в эфир.
  Показ системным `SW_SHOWNA` без активации: iRacing не теряет клавиатуру
  (штатный show() pywebview её забирает — проверено). Окна служебные: нет в
  панели задач и Alt+Tab. Размер — системным вызовом без показа;
- **в OBS** — та же страница `/ov/<id>` источником browser source.

Правки пользователя лежат в `<данные>/overlays/<id>.json` поверх умолчаний;
открытые оверлеи подхватывают новое описание за пару секунд.

## Редактор оверлеев

Панель → «Оверлеи трансляции» → «Редактор оверлеев» (адрес `/editor`).
В центре — настоящий оверлей на живых данных (без сима — кнопка
«Демо-данные»), слева оверлеи и слои, справа свойства.

- **Холст:** клик — выбрать элемент, тащить — двигать, ручки — размер;
  стрелки двигают на 1 px (Shift — на 10), Del удаляет, Ctrl+D копирует,
  Ctrl+Z / Ctrl+Y — отмена и возврат, Ctrl+S — сохранить.
- **Элементы:** текст, чип, плашка, картинка — в шапку, строку/ячейку/
  карточку или подвал. Текст — шаблон с полями данных («Вставить поле»).
- **Форма:** прямоугольник, скругление, капсула, параллелограмм, срез
  справа или слева; заливка своим цветом, из палитры или цветом класса.
- **Оверлей целиком:** ширина, высота строк, отступы, колонки и листание
  решётки, шапка и подвал, скругление, тень, полоса флага, появление.
- **Палитра и шрифты:** цвета оверлея, шрифт для цифр и для текста,
  свои шрифты (ttf/otf/woff) и логотипы (png/jpg/webp/svg) загрузкой.
- «Сохранить» пишет описание на сервер — окна в эфире и страницы в OBS
  подхватывают его за пару секунд. «Вернуть исходный вид» удаляет правки
  оверлея после подтверждения.

## Оверлеи трансляции

Выводятся **окнами поверх iRacing**: перетаскиваются мышью, запоминают место,
показом управляет пульт. В эфир попадают через захват экрана в OBS — оператор
на одном мониторе видит ровно то же, что зритель.

Пульт эфира — тоже окно поверх сима: зелёная точка показывает, что сейчас в
кадре. С телефона он же открывается по адресу `/deck` (нужно включить доступ
по сети в панели).

Для схемы с двумя машинами те же оверлеи доступны страницами и добавляются в
OBS как **browser source**:

| Оверлей | Адрес |
|---|---|
| Башня позиций | `/ov/tower` |
| Стартовая решётка | `/ov/grid` |
| Плашка комментаторов | `/ov/commentators` |
| Дельта пилотов | `/ov/delta` |
| Пит-стопы | `/ov/pits` |

Полный адрес — `http://127.0.0.1:8777` + путь.

Фон страниц прозрачный. Настройки (заголовок, число строк, режим гэпа,
машина в фокусе) — во вкладке «Оверлеи трансляции» в панели.

## Запуск из исходников без риска для боевых данных

```
set IRC_DATA_DIR=%TEMP%\irc-test
python run.py
```
Без этой переменной пробный запуск пишет настройки в рабочую папку — и потом
установленное приложение стартует с чужим портом.
