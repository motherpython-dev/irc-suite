# iRC

Одно приложение для организатора лиги iRChamps. Модули включаются независимо
и делят общие ресурсы: один клиент iRacing, один HTTP-сервер, один значок в
трее.

## Модули

| Модуль | Состояние |
|---|---|
| **Рейс-контрол** | лента инцидентов, перемотка повтора, флаги и штрафы |
| **Оверлеи трансляции** | башня, решётка, комментаторы, дельта, пит-стопы; пульт с макросами; редактор |
| **RUTP** | управление внешним агентом ливрей (нужен агент 1.3.0+) |
| **Телеметрия** | позже |

## Быстрый старт разработчика

```
pip install -r requirements.txt
set IRC_DATA_DIR=%TEMP%\irc-test
python run.py
```

Без `IRC_DATA_DIR` пробный запуск пишет в боевую папку `%LOCALAPPDATA%\iRC`.
Сборка и выпуск — [docs/TECHNICAL.md, раздел 15](docs/TECHNICAL.md#15-сборка-и-выпуск).

## Главное правило оверлеев

Одно JSON-описание рисуют два отрисовщика: `web/ov/render.js` (OBS, редактор)
и `core/ui/ov_paint.py` (окна поверх iRacing). Меняешь смысл описания в
одном — сверяй с другим.
